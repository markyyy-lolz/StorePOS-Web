Essential information about how StorePOS works.

Read the manual ↗
Does StorePOS work with Android tablets?+

Yes, StorePOS Android supports compatible tablets. Check exact hardware compatibility, Bluetooth permissions and printer protocol before using it for live sales.

Can two tablets share one receipt printer?+

StorePOS Android v1.7.0 includes a designated printer host and cloud FIFO queue for two tablets with one VOZY G80. Physical acceptance testing is still required.

Does it work when the internet is down?+

Supported Android sales can be held in a local offline queue for sync. Cloud, PayMongo verification and shared online printer dispatch require network access.

Can I accept online PayMongo payments?+

Enabled merchants can configure automatic QR Ph with verified payment status. Online card checkout and NFC card-present acceptance require separate payment-provider availability and approval.

How much does StorePOS cost?+

The available cloud plans are displayed above. Custom software licenses start at ₱699/month; final price varies by device count, staff, modules, branches and support.
